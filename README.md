# Event Marketplace (SDM2)

A clean, fast, and role-based event management system designed to make event planning easier. This application handles secure user registration, permissions, and a dynamic schedule tailored for different user roles (Admins, Speakers, and Attendees).

## 🚀 Tech Stack

* **Backend:** Python / Django (managed via `uv`)
* **Frontend:** React (scaffolded with Vite) + tailwind css
* **Database:** Postgresql
